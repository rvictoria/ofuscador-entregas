# Ofuscador · entregas

Aquí solo se publican los instaladores del Ofuscador y el archivo que dice cuál es la última
versión. El programa consulta ese archivo para avisar de que hay una versión nueva.

El Ofuscador protege los datos de tus clientes antes de que lleguen a una IA: los sustituye por
etiquetas en tu equipo y los devuelve al leer la respuesta. El catálogo y las conversaciones se
guardan cifrados en el propio equipo.

- Última versión: mira la pestaña **Releases**.
- Cada instalador va firmado; el programa solo acepta actualizaciones firmadas con esa clave.
